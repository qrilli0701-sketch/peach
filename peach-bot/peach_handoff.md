## 2. 구성 파일

### peach-bot/ (Python, 시트 직접 기록용 — 오케스트레이터가 사용)
- `peach.py` — 시트 CLI: `add`, `add-checked`, `count`, `recent`, `search`(중복), `delete-last`, `delete-name`, `highlight`(빈칸 노란음영), `backup`, `restore`
- `validate.py` — 기록 직전 검증. **현재 전화번호 자릿수만** 판정(010=11자리). 주소(juso)/시도 검사 함수는 남아있지만 미사용
- `.claude/agents/peach-reader|checker|lead.md` — 손글씨 판독팀(파일 경로 있는 이미지에만)
- `.env`, `gen-lang-client-...json` — **git 제외(비밀)**. 새 컨테이너에선 사용자가 파일 재첨부해야 함

### peach-bot/webform/ (Google Apps Script 웹앱 — 사용자 구글 계정에서 실행)
- `Code.gs` — 웹폼 제출 → `주문접수` 탭 적재. 전화번호 열 텍스트 서식(앞자리 0 보존)
- `Page.html` — 손님용 주문 폼
  - 보내는분 1회 + 받는분 카드 "추가" 다건, 비고(선택)
  - 연락처 숫자만·11자리 강제, 수량 1 이상 정수 검증
  - 하단 요약바: 받는 분 수·총 박스·예상금액(박스×4만 + 택배 5천/2박스 묶음)
  - 상단 복숭아 사진 배너(`IMG_URL` 드라이브 썸네일), 가격·꿀팁·안내사항 카드
  - "📦 대량 주문은 여기로!" — 엑셀 양식 다운로드 버튼(`BULK_XLSX_URL`)
  - 완료 후 `resetForm()`(iframe 새로고침 멈춤 회피)
- `Admin.gs` + `AdminPage.html` — 가족용 관리자 화면(웹앱 주소 + `?admin`). 주문 묶음 목록·상세·확인 버튼. 확인하면 `주문접수` 상태 `확인` + J열 확인자 / K열 확인시각. 비밀번호는 스크립트 속성 `ADMIN_PASSWORD`
- `Gmail.gs` — 대량주문 메일 자동 수집
  - `qrilli0701@gmail.com` 으로 온 xlsx 첨부를 5분 트리거로 확인 → 시트 변환(Drive 고급서비스 v3 create / v2 insert 폴백) → 파싱 → `주문접수` 적재 → 메일에 `임가네처리완료` 라벨
  - 필수값 누락 시 `확인필요` + 노란음영 + 비고 `[미비:...]`
- `임가네_대량주문_양식.xlsx` — 대량주문 엑셀 양식 원본
- `README.md` — 배포/설치 방법

## 3. 결정된 운영 규칙
1. **기록 전 사용자 확인** — 정리 표 먼저 보여주고 "넣어" 하면 기록
2. **검증은 전화번호 자릿수만** 자동, 주소·이름은 사람이 확인. **자동 교정 금지**(원문 보존)
3. **불확실·누락은 노란음영**
4. 붙여넣기 이미지/텍스트는 파일경로가 없어 판독팀 서브에이전트 사용 불가 → 직접 판독(이중 확인)
5. 주소 juso API는 원격 세션에서 egress 차단 — 쓰지 않음
6. 사용자는 git commit 메시지에 지정된 Co-Authored-By/Claude-Session 라인 사용

## 4. 배포/수정 방식 (중요)
- Apps Script 코드는 **사용자 구글 계정 프로젝트("복숭아 주문")** 안에 있음 → Claude가 직접 못 올림
- 지금까지: 레포에서 수정 → 사용자가 script.google.com 에 **복사·붙여넣기** → 웹앱은 **배포 관리 → 새 버전**으로 재배포
- 제안 중(미완): 맥북에서 `clasp` 세팅 → 이후 `git pull && clasp push` 로 붙여넣기 제거
  - `npm i -g @google/clasp` → `clasp login` → Apps Script API 사용 설정 → `webform/` 에서 `clasp clone <스크립트ID> --rootDir .` (실제 appsscript.json 보존)
