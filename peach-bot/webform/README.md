# 복숭아 주문 접수 웹앱

보내는사람은 한 번만 입력하고 받는사람은 원하는 만큼 추가하는 주문 접수 페이지.
제출하면 받는사람 수만큼 스프레드시트 **`주문접수` 탭**에 여러 줄로 쌓인다(검토용 큐).

## 배포 방법 (사장님 구글 계정에서)

1. https://script.google.com 접속 → 로그인 → **새 프로젝트**
2. 기본 `Code.gs` 내용을 지우고 → 이 폴더의 **`Code.gs`** 내용 붙여넣기
3. 왼쪽 파일 목록 **+ → HTML** → 이름을 정확히 **`Page`** 로 만들고 → **`Page.html`** 내용 붙여넣기
4. 오른쪽 위 **배포 → 새 배포**
5. 유형(톱니바퀴) → **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
6. **배포** → 권한 승인(본인 계정)
7. 나오는 **웹 앱 URL**을 카톡으로 손님에게 공유

## 동작
- 연락처는 `- 없이 숫자 11자리` 형식을 입력 단계에서 검증
- 필수항목(성함·연락처·주소·수량) 누락 시 제출 안 됨 → 접수 단계에서 오류 차단
- `주문접수` 탭 열: 접수시각 · 받는사람 · 받는분전화번호 · 수량 · 주소 · 보내는사람 · 보내는분전화번호 · 비고(품종) · 상태

## 검토 → 기록 흐름
1. 손님이 폼으로 접수 → `주문접수` 탭에 `상태=접수`로 쌓임
2. 사용자가 검토
3. 확정분을 기록 시트로 옮김(peach.py 또는 수동), 옮긴 행은 `상태`를 `완료` 등으로 변경

> 스프레드시트 ID는 `Code.gs` 상단 `SPREADSHEET_ID` 에 들어 있다. 시트가 바뀌면 그 값만 교체.

## 대량주문 — 메일 자동 수집 (Gmail.gs)

단체 손님이 `임가네_대량주문_양식.xlsx` 를 채워 **qrilli0701@gmail.com** 으로 보내면,
Apps Script(같은 프로젝트)가 그 메일을 자동으로 읽어 `주문접수` 탭에 적재한다.

설치:
1. 같은 Apps Script 프로젝트에 **`Gmail.gs`** 파일 추가 후 내용 붙여넣기
2. 편집기 왼쪽 **서비스(+) → `Drive API` 추가** (식별자 `Drive`) — 엑셀→시트 변환용
3. 함수 목록에서 **`setupTrigger`** 한 번 실행 → 권한 승인 → 5분마다 자동 확인 트리거 생성
4. 끝. 이후 메일이 오면 자동으로 `주문접수` 탭에 `상태=접수`, 비고에 `[메일:보낸사람]` 표시

동작/주의:
- 우리 양식(9행 헤더 '받는사람', 10행부터 받는분)만 인식하고, 아니면 건너뜀
- 예시 행(김복숭)은 자동 제외
- 전화번호 앞자리 0 이 사라진 경우 자동 복원(10자리·1로 시작 → 0 붙임)
- 처리한 메일엔 `임가네처리완료` 라벨을 붙여 중복 방지

> 참고: Claude(나)가 메일함을 직접 읽는 게 아니라, **이 스크립트가 사장님 계정에서 메일을 읽어 시트에 넣고**, 나는 그 `주문접수` 탭을 읽어 검토·기록한다.
