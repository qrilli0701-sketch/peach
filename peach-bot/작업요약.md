# 복숭아 주문봇 작업 요약

## 프로젝트 개요
텔레그램으로 복숭아 농산물 주문(텍스트/이미지)을 받아 Gemini AI로 파싱한 뒤 Google 스프레드시트에 자동 기록하는 봇.

## 파일 구성
- `bot.py` - 1인용 버전 (개인 채팅 전용)
- `bot_v2.py` - **그룹 채팅 지원 버전 (현재 사용 중, 최신)**
- `.env` - 환경변수 (텔레그램 토큰, Gemini API 키, 스프레드시트 ID 등) — 별도 보관 필요, 이 프로젝트 폴더에 있어야 함
- Google 서비스 계정 credentials 파일 — `.env`의 `GOOGLE_CREDENTIALS_FILE` 경로 확인 필요

## bot_v2.py 주요 기능
1. **주문 파싱**: 텍스트/이미지 주문 → Gemini(`gemini-2.5-flash-lite`)로 항목 추출
   - 항목: 받는사람, 받는분전화번호, 수량, 주소, 보내는사람, 보내는분전화번호, 비고
   - 받는사람/보내는사람 혼동 방지 프롬프트 처리됨
   - 전화번호 축약(010...1234)은 null 처리
2. **확인 후 기록**: 인라인 버튼(✅기록/❌취소)으로 사용자 확인 거쳐 스프레드시트에 저장
3. **주문 수정**: "고쳐줘/수정해줘/바꿔줘/바꾸/변경/정정" 같은 **명시적 수정 키워드**가 있을 때만 대기 중인 주문 수정으로 인식 (그 외엔 새 주문 또는 일반 대화로 처리)
4. **새 주문 시 이전 대기 자동 취소**: 대기 주문 있는 상태에서 확인/취소 안 누르고 새 주문(이미지 or 긴 텍스트)을 보내면 이전 대기 주문 자동 취소 후 새 주문 진행
5. **그룹 채팅 지원**: `(chat_id, user_id)` 조합으로 그룹 내 각 사용자의 대기 주문을 개별 관리, 주문자 이름 표시
6. **키워드 기반 명령 (API 호출 없음, 정규식 처리)**:
   - "몇 건/몇 개/얼마나" → 건수 조회
   - "최근 N건 보여줘" → 최근 조회
   - "마지막 N건 지워줘" → 삭제 (확인 버튼 거침)
   - "이름 지워줘" → 이름으로 삭제 (확인 버튼 거침)
   - "전체 지워/초기화" → 전체 삭제 (확인 버튼 거침)
   - 인사말 → 고정 응답
7. **일반 대화**: 위 조건에 안 걸리면 Gemini와 자유 대화
8. **스프레드시트 헤더**: `입력시각(시분초 포함), 받는사람, 받는분전화번호, 수량, 주소, 보내는사람, 보내는분전화번호, 비고, 입력자`
   - 헤더 불일치 시 기존 데이터 보존하며 헤더만 갱신
   - 데이터 유효성 검사(validation) 규칙 시작 시 자동 제거 (gspread 저장 오류 방지)
   - `value_input_option="RAW"`로 저장 (자동 타입 변환 방지)

## 해결한 이슈들
- Gemini 모델 `gemini-2.0-flash-lite` → 지원 중단됨. `gemini-2.5-flash-lite`로 교체
- API 버전 `v1` → `v1beta`로 변경 (신모델 지원 안 되던 문제)
- 무료 할당량: `gemini-2.5-flash-lite`는 **하루 20회**로 매우 적음 (RPM 10회)
  - 테스트 중 자주 429(RESOURCE_EXHAUSTED) 발생
  - 결제 등록 시 한도 상승 논의 중 (사용자가 결제하기로 함, 아직 미등록)
- 503(UNAVAILABLE) 오류는 Gemini 서버 자체 일시 과부하, 재시도 로직 논의했으나 아직 미구현
- 스프레드시트 append 시 400 APIError(데이터 유효성 검사 충돌) → validation 제거 코드로 해결
- 봇 재시작 시 메모리(pending_orders 등)가 초기화되어 이전 대화의 확인 버튼이 무효해짐 (알려진 제약, 영속화 미구현)
