**변경: 이 프로젝트 대화창에 이미지를 붙여넣으면 Claude가 직접 판독 → 확인 → 시트 기록**

없어진 것: 텔레그램 봇 실행/24시간 서버, Gemini API 키와 하루 20회 무료 한도, 인라인

기존 봇 파일(`bot.py`, `bot_v2.py`)은 지우지 않고 그대로 뒀다. 원하면 언제든 병행 사용 가능.

## 구성

| 파일 | 역할 |
|---|---|
| `peach.py` | 시트 입출력 전용 CLI (gspread만 사용, Gemini/텔레그램 없음) |

## 사용법

1. 이 폴더에서 대화 중 주문서 **이미지를 붙여넣거나 주문 텍스트를 붙여넣는다.**
2. Claude가 항목을 표로 정리해 보여준다. 빠진 필수값이 있으면 짚어준다.
3. 확인하면 시트에 기록. 틀린 게 있으면 말로 고치면 됨.

## 실전 운영 (2026-07-24~)

시트의 데이터는 **실제 배송될 주문**이다. 안전장치:

1. 삭제·복원은 `--commit` 없이는 시트를 건드리지 않는다 (미리보기)
2. `--commit` 실행 시 직전 상태를 `backups/` 에 CSV로 자동 저장
3. `clear` 는 현재 건수를 정확히 맞춰야만 실행 (`--confirm-count`)
4. `add` 는 `받는사람` 빈 행이 하나라도 있으면 **전체 기록을 중단** (인코딩 깨짐 방어)

## 시트 스펙 (기존과 동일)

헤더: `입력시각, 받는사람, 받는분전화번호, 수량, 주소, 보내는사람, 보내는분전화번호, 비고`

(`입력자` 열은 2026-07-24 제거 — 대화형으로 바뀌어 입력자가 항상 한 명이라 의미가 없어짐)

- 헤더 불일치 시 기존 데이터 보존하며 헤더만 갱신 (`add` 실행 시)
- 데이터 유효성 검사 규칙 자동 제거 (append 400 오류 방지)
- `value_input_option="RAW"` 저장, Sheets 429/5xx 는 지수 백오프 재시도
- 윈도우 cp949 콘솔 대응으로 stdout을 UTF-8로 재설정

## 판독 규칙

- 없거나 불확실하면 빈 값. 추측 금지
- 전화번호 축약(`010...1234`)이면 빈 값
- 받는사람(고객) / 보내는사람(발송인) 혼동 금지
- 이미지 한 장에 여러 건이면 각각 별도 행
