# 우리 아이 — 아이 관리 웹앱

부부가 같은 화면에서 **이번 달 챙길 것**과 **잘 크고 있는지**를 보는 모바일 웹앱.
Google Apps Script + 구글시트로 돌아가며 서버 비용이 없다.

- 기능 범위·데이터 모델·리스크: [기획.md](기획.md)
- 화면 4개: 🏠 오늘 / 📈 성장 / 💉 일정 / 📝 기록

## 지금 되는 것

| | 내용 |
|---|---|
| **접종·검진 자동 일정** | 생년월일만 넣으면 표준예방접종(14종) + 영유아검진 8차 + 구강검진 4회 + 행정 기한이 **날짜로 환산**되어 나온다 |
| **지연 자동 반영** | 앞 차수를 늦게 맞으면 다음 차수 창을 `실제 접종일 + 최소간격` 으로 다시 계산한다 |
| **성장 백분위** | 키·몸무게·머리둘레·BMI·키대비몸무게를 WHO 성장표준으로 z-score / 백분위 산출 |
| **백분위 그래프** | 3·15·50·85·97 밴드 위에 우리 아이 곡선. 외부 라이브러리 없이 SVG 직접 생성 |
| **추세 경고** | "체중 백분위가 75p → 20p 로 떨어졌습니다" — 절대값보다 곡선을 가로지르는 변화가 중요한 신호다 |
| **생활기록** | 수유·이유식·수면·배변·체온·투약을 탭 한 번으로. 오늘 요약이 부부 인수인계용으로 홈에 뜬다 |
| **새 재료 관찰** | 처음 먹이는 재료를 체크해 두면 3일간 홈에 뜬다. 나중에 뭐가 문제였는지 역추적할 수 있다 |
| **독감 시즌 관리** | 매년 9월~4월 시즌마다 항목이 생긴다. 생애 첫 접종이면 4주 간격 2회, 이후 매 시즌 1회 |
| **일괄 입력** | 이미 큰 아이를 등록하면 지난 항목이 수십 개다. 아기수첩 보고 한 번에 체크해 넣는 화면이 있다 |
| **주간 메일** | 매주 정해진 요일 아침, 부부 둘 다에게 이번 주 할 일 요약 |
| **캘린더 연동** | 30일 내 마감 항목을 구글 캘린더에 종일 일정으로 — 휴대폰 기본 알림으로 뜬다 |
| **주간 백업** | 스프레드시트 사본을 Drive `백업` 폴더에 (최근 8개 보관) |

## 설치

**→ [배포.md](배포.md) 에 단계별 체크리스트가 있습니다.** (약 15분)

붙여넣을 파일은 두 개뿐입니다:

| 파일 | Apps Script 에서 |
|---|---|
| `dist/배포용_전체코드.gs` | 기본 `Code.gs` 내용을 지우고 통째로 붙여넣기 |
| `dist/Page.html` | ＋ → HTML → 이름 **`Page`** 로 만들어 붙여넣기 |

그 다음 `SPREADSHEET_ID` 교체 → `setupSheets` 실행 → 웹앱 배포 → `installTriggers` 실행.

배포 설정 두 가지만 주의하세요:

- **실행 계정 = 웹 앱에 액세스하는 사용자** (누가 기록했는지 알기 위해)
- **액세스 권한 = 모든 Google 계정 사용자** — "모든 사용자"(로그인 없음)로 두면 안 됩니다

clasp 를 쓰면 `clasp push` 한 줄로 끝납니다. `src/appsscript.json` 에 설정이 들어 있습니다.

## 개발

```bash
npm install     # 교차검증용 devDependency (who-growth-standards)
npm test        # 98개 테스트
npm run bundle  # src/ → dist/배포용_전체코드.gs 재생성
npm run preview # localhost:8787 에서 화면 미리보기 (배포 없이)
npm run shots   # dist/preview/ 에 라이트·다크 스크린샷 저장
```

`npm run preview` 는 `google.script.run` 을 로컬 HTTP 로 바꿔치고 그 뒤를 가짜 Apps Script
런타임에 물린다. 즉 **배포하지 않고도 진짜 데이터 경로로 화면을 볼 수 있다.**
디자인을 고칠 때는 이걸 켜두고 작업하는 편이 빠르다.

계산 로직(`lib_growth.gs`, `lib_schedule.gs`)은 Apps Script API 를 전혀 쓰지 않는
**순수 함수**라 node 에서 그대로 돌아간다. `test/load.js` 가 `.gs` 를 vm 컨텍스트에 올린다.
`test/appsscript.mock.js` 는 시트·메일·캘린더를 메모리로 흉내 내서
`Api.gs` 전체 흐름을 편집기에 붙여넣기 전에 검증한다.

| 테스트 | 무엇을 지키는가 |
|---|---|
| `growth.test.js` | 정규분포 함수 정확도, WHO 공표 중앙값, 날짜 계산, 추세 감지 |
| `growth.reference.test.js` | 압축한 LMS 표가 WHO 원본 일 단위 표와 일치하는지 (최악 0.008 z) |
| `schedule.test.js` | 접종·검진 창, 지연 시 재계산, 말일 경계, 독감 시즌 규칙 |
| `api.test.js` | 전체 흐름, 아이별 데이터 분리, 권한, 메일 이스케이프, 일괄 입력, 이유식 관찰 |
| `syntax.test.js` | 붙여넣기 전 문법·태그 균형·프런트가 부르는 액션 존재 여부 |
| `bundle.test.js` | 실제로 붙여넣는 `dist/` 파일이 src 와 같은지, 그 한 파일만으로 도는지 |
| `ui.test.js` | 크로미움으로 실제 렌더링. 가로 넘침, 스위치 위치, 시트 정렬, 다크 모드 |

**`src/` 를 고쳤으면 `npm run bundle` 을 잊지 마세요.** 테스트가 확인해 주긴 합니다.

LMS 표를 다시 만들려면 `npm run gen:lms` (`tools/gen_lms.js` — 격자 오차도 같이 출력한다).

## 주의

- **접종·검진 일정은 참고용이다.** 최종 확인은 [예방접종도우미](https://nip.kdca.go.kr)와 소아과.
  접종이 지연되면 남은 횟수·간격이 표준과 달라질 수 있다.
- **약 용량은 자동 계산하지 않는다.** 처방받은 용량을 그대로 입력만 한다. 오입력 위험이 크다.
- 성장 백분위는 WHO 성장표준(0~5세) 기준. 한국 2017 성장도표는 0~35개월 구간에서
  이 표준을 그대로 채택하므로 일치하지만, **만 3세 이상은 KDCA 고유 데이터로 교체가 필요하다.**
