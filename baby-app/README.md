# 우리 아이 — 아이 관리 웹앱

부부가 같은 화면에서 **이번 달 챙길 것**과 **잘 크고 있는지**를 보는 모바일 웹앱.
Google Apps Script + 구글시트로 돌아가며 서버 비용이 없다.

- 기능 범위·데이터 모델·리스크: [기획.md](기획.md)
- 화면 4개: 🏠 오늘 / 📈 성장 / 💉 일정 / 📝 기록

## 지금 되는 것

| | 내용 |
|---|---|
| **접종·검진 자동 일정** | 생년월일만 넣으면 표준예방접종(14종) + 영유아검진 8차 + 구강검진 4회 + 행정 기한이 **날짜로 환산**되어 나온다 |
| **지연 자동 반영** | 앞 차수를 늦게 맞으면 다음 차수 창을 `실제 접종일 + 최소간격` 으로 다시 계산한다 |
| **성장 백분위** | 키·몸무게·머리둘레·BMI·키대비몸무게를 WHO 성장표준으로 z-score / 백분위 산출 |
| **백분위 그래프** | 3·15·50·85·97 밴드 위에 우리 아이 곡선. 외부 라이브러리 없이 SVG 직접 생성 |
| **추세 경고** | "체중 백분위가 75p → 20p 로 떨어졌습니다" — 절대값보다 곡선을 가로지르는 변화가 중요한 신호다 |
| **생활기록** | 수유·식사·수면·배변·체온·투약을 탭 한 번으로. 오늘 요약이 부부 인수인계용으로 홈에 뜬다 |
| **주간 메일** | 매주 정해진 요일 아침, 부부 둘 다에게 이번 주 할 일 요약 |
| **캘린더 연동** | 30일 내 마감 항목을 구글 캘린더에 종일 일정으로 — 휴대폰 기본 알림으로 뜬다 |
| **주간 백업** | 스프레드시트 사본을 Drive `백업` 폴더에 (최근 8개 보관) |

## 설치

### 1. 스프레드시트 만들기
새 구글 스프레드시트를 만들고 **아내분 계정과 공유**(편집자)한다.
주소창의 `https://docs.google.com/spreadsheets/d/`**`이 부분`**`/edit` 이 스프레드시트 ID.

### 2. Apps Script 프로젝트
1. <https://script.google.com> → **새 프로젝트**
2. `src/` 의 **`.gs` 파일 9개**를 같은 이름으로 각각 만들어 붙여넣는다
   `Code` `Api` `Store` `Setup` `Triggers` `lib_growth` `lib_schedule` `data_lms` `data_schedule`
   (편집기에서 파일명에 `.gs` 는 자동으로 붙는다)
3. 왼쪽 **+ → HTML** → 이름 **`Page`** → `src/Page.html` 내용 붙여넣기
4. **`Setup.gs` 맨 위 `SPREADSHEET_ID`** 를 1번에서 복사한 ID 로 교체

> 파일이 많아 손으로 옮기기 번거로우면 [clasp](https://github.com/google/clasp) 를 쓴다:
> `npm i -g @google/clasp && clasp login && clasp create --type webapp && clasp push`

### 3. 초기화
편집기 함수 목록에서 **`setupSheets`** 선택 → **실행** → 권한 승인.
탭 7개(`설정` `아이` `성장기록` `일정완료` `할일` `생활기록` `병원`)가 생긴다.

`설정` 탭에서 채울 것:

| 키 | 값 예시 |
|---|---|
| 허용이메일 | `남편@gmail.com, 아내@gmail.com` — **여기 적힌 계정만 앱이 열린다** |
| 이름표 | `남편@gmail.com=아빠, 아내@gmail.com=엄마` (기록자 표시용, 선택) |
| 알림요일 | `1` (1=월 … 7=일) |
| 알림시각 | `8` |
| 캘린더ID | 비워두면 기본 캘린더 |

### 4. 배포
**배포 → 새 배포 → 유형(톱니바퀴) → 웹 앱**

| 항목 | 값 | 왜 |
|---|---|---|
| 실행 계정 | **웹 앱에 액세스하는 사용자** | 누가 기록했는지 알 수 있고, 시트 권한이 2차 방어선이 된다 |
| 액세스 권한 | **모든 Google 계정 사용자** | 구글 계정 로그인은 요구하되, 실제 통과는 허용이메일 + 시트 공유로 거른다 |

> ⚠️ 액세스를 "모든 사용자"(로그인 없음)로 두지 말 것. 아이 건강정보다.

나온 URL 을 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있다.

### 5. 자동화 켜기
함수 목록에서 **`installTriggers`** 실행 → 권한 승인.
주간 요약 메일 / 매일 캘린더 동기화 / 주간 백업 트리거가 걸린다.

설치가 잘 됐는지 확인: **`checkSetup`** 실행 후 실행 로그 확인.

## 개발

```bash
npm install     # 교차검증용 devDependency (who-growth-standards)
npm test        # 69개 테스트
```

계산 로직(`lib_growth.gs`, `lib_schedule.gs`)은 Apps Script API 를 전혀 쓰지 않는
**순수 함수**라 node 에서 그대로 돌아간다. `test/load.js` 가 `.gs` 를 vm 컨텍스트에 올린다.
`test/appsscript.mock.js` 는 시트·메일·캘린더를 메모리로 흉내 내서
`Api.gs` 전체 흐름을 편집기에 붙여넣기 전에 검증한다.

| 테스트 | 무엇을 지키는가 |
|---|---|
| `growth.test.js` | 정규분포 함수 정확도, WHO 공표 중앙값, 날짜 계산, 추세 감지 |
| `growth.reference.test.js` | 압축한 LMS 표가 WHO 원본 일 단위 표와 일치하는지 (최악 0.008 z) |
| `schedule.test.js` | 접종·검진 창, 지연 시 재계산, 말일 경계 |
| `api.test.js` | 전체 흐름, 아이별 데이터 분리, 권한, 메일 이스케이프 |
| `syntax.test.js` | 붙여넣기 전 문법·태그 균형·프런트가 부르는 액션 존재 여부 |

LMS 표를 다시 만들려면 `npm run gen:lms` (`tools/gen_lms.js` — 격자 오차도 같이 출력한다).

## 주의

- **접종·검진 일정은 참고용이다.** 최종 확인은 [예방접종도우미](https://nip.kdca.go.kr)와 소아과.
  접종이 지연되면 남은 횟수·간격이 표준과 달라질 수 있다.
- **약 용량은 자동 계산하지 않는다.** 처방받은 용량을 그대로 입력만 한다. 오입력 위험이 크다.
- 성장 백분위는 WHO 성장표준(0~5세) 기준. 한국 2017 성장도표는 0~35개월 구간에서
  이 표준을 그대로 채택하므로 일치하지만, **만 3세 이상은 KDCA 고유 데이터로 교체가 필요하다.**
