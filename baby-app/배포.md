# 배포 체크리스트

붙여넣을 파일은 **두 개**입니다.

- `dist/배포용_전체코드.gs` — 코드 전부를 한 파일로 합친 것
- `dist/Page.html` — 화면

소요 시간 약 15분. 순서대로 하시면 됩니다.

---

## 1. 스프레드시트 만들기 · 2분

1. <https://sheets.new> 접속 → 빈 시트가 생깁니다
2. 이름을 **`우리아이`** 로 바꿉니다
3. 오른쪽 위 **공유** → **아내분 Gmail 주소** 추가 → 권한 **편집자** → 보내기
4. 주소창에서 **ID를 복사**해 둡니다

```
https://docs.google.com/spreadsheets/d/  1AbC...xYz  /edit
                                         ↑ 이 부분만
```

> 이 시트 공유 목록이 **실질적인 최종 방어선**입니다. 여기 없는 사람은 앱이 열려도 데이터를 못 읽습니다.

## 2. Apps Script 프로젝트 · 3분

1. <https://script.google.com/home/projects/create> 접속
2. 프로젝트 이름(왼쪽 위 "제목 없는 프로젝트")을 **`우리아이`** 로
3. 기본으로 열려 있는 `Code.gs` 내용을 **전부 지우고** → `dist/배포용_전체코드.gs` 내용을 **전부 붙여넣기**
4. 맨 위쪽 **`SPREADSHEET_ID`** 줄을 찾아 1번에서 복사한 ID로 교체

```js
var SPREADSHEET_ID = 'PUT_YOUR_SPREADSHEET_ID_HERE';   // ← 여기
```

5. 왼쪽 파일 목록 **＋ → HTML** → 이름을 정확히 **`Page`** (확장자 없이)
   → 기본 내용 지우고 `dist/Page.html` 내용 붙여넣기
6. **저장**(Ctrl+S)

> 파일 이름이 `Page` 가 아니면 화면이 안 뜹니다. `Page.html` 로 쓰지 마세요 — 편집기가 `.html` 을 자동으로 붙입니다.

## 3. 시트 초기화 · 2분

1. 편집기 위쪽 함수 드롭다운에서 **`setupSheets`** 선택 → **실행**
2. 권한 요청이 뜹니다 → **권한 검토** → 본인 계정 선택
3. **"Google에서 확인하지 않은 앱"** 경고가 뜹니다 (본인이 만든 앱이라 정상)
   → **고급** → **우리아이(안전하지 않음)으로 이동** → **허용**
4. 실행이 끝나면 스프레드시트에 탭 7개가 생깁니다

이제 스프레드시트 **`설정` 탭**을 열어 채웁니다:

| 키 | 값 |
|---|---|
| 허용이메일 | `본인@gmail.com, 아내분@gmail.com` |
| 이름표 | `본인@gmail.com=아빠, 아내분@gmail.com=엄마` |
| 알림요일 | `1` (월요일) |
| 알림시각 | `8` |
| 캘린더ID | 비워두기 |

> `허용이메일` 에 아내분 주소를 넣지 않으면 아내분이 못 들어옵니다. 쉼표로 구분하세요.

## 4. 웹앱 배포 · 3분

**배포 → 새 배포 → 유형 선택(⚙️) → 웹 앱**

| 항목 | 값 |
|---|---|
| 설명 | `v1` |
| **실행 계정** | **웹 앱에 액세스하는 사용자** |
| **액세스 권한** | **모든 Google 계정 사용자** |

**배포** → 나오는 **웹 앱 URL** 복사.

> ⚠️ 액세스 권한을 **"모든 사용자"** 로 두지 마세요. 그건 로그인 없이 누구나 열립니다.
> **"모든 Google 계정 사용자"** 여야 구글 로그인을 요구하고, `허용이메일` 로 거를 수 있습니다.

### 확인
URL을 **시크릿 창**에서 열어보세요. 로그인을 요구하면 정상입니다.
본인 계정으로 로그인하면 아이 등록 화면이 떠야 합니다.

## 5. 자동화 켜기 · 1분

함수 드롭다운에서 **`installTriggers`** 선택 → **실행** → 권한 승인
(메일·캘린더 권한을 새로 물어봅니다)

이걸로 월요일 아침 8시 요약 메일, 매일 7시 캘린더 동기화, 일요일 새벽 백업이 걸립니다.

## 6. 휴대폰에 올리기 · 1분

URL을 두 분 휴대폰에서 열고:

- **아이폰** Safari → 공유 버튼 → **홈 화면에 추가**
- **안드로이드** Chrome → ⋮ → **홈 화면에 추가**

앱 아이콘처럼 생깁니다.

## 7. 첫 입력 · 3분

1. **아이 설정** → 이름, 생년월일 `2026-03-21`, 성별 `남` → 저장
2. **💉 일정** 탭 → 위에 뜨는 **"한번에 입력하기"**
   → 아기수첩 보면서 지금까지 맞은 것 체크 → 저장
   - 날짜를 아는 건 정확히 넣으세요. 다음 차수 창이 그 날짜 기준으로 다시 잡힙니다.
   - 모르면 그대로 두면 기한 마지막 날로 추정 입력됩니다.
3. **📈 성장** 탭 → 최근 키·몸무게 입력 → 백분위가 바로 뜹니다
4. **로타바이러스 종류 선택** — 로타릭스(2회) / 로타텍(3회) 중 맞고 계신 것

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| 화면이 안 뜨고 빈 페이지 | HTML 파일 이름이 `Page` 가 아님 |
| `시트 탭이 없습니다` | `setupSheets` 를 아직 안 돌림 |
| `접근 권한이 없습니다` | `설정` 탭 `허용이메일` 에 그 주소가 없음 |
| 아내분만 안 열림 | 허용이메일 누락 + 스프레드시트 공유 누락 둘 다 확인 |
| 코드를 고쳤는데 반영이 안 됨 | **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** |

마지막 줄이 제일 자주 걸립니다. Apps Script 는 코드를 저장해도 **새 버전으로 다시 배포해야** 웹앱에 반영됩니다. (URL 은 그대로 유지됩니다)

## clasp 를 쓰신다면 (선택)

붙여넣기 대신 명령 한 줄로도 됩니다.

```bash
npm i -g @google/clasp
clasp login
cd baby-app
clasp create --type webapp --title 우리아이 --rootDir src
clasp push
```

`src/appsscript.json` 에 타임존·실행권한·OAuth 범위가 이미 들어 있어서,
`clasp push` 하면 4번의 배포 설정이 자동으로 맞춰집니다.
`SPREADSHEET_ID` 교체와 `setupSheets` 실행은 그래도 직접 하셔야 합니다.
